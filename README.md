## Featured Projects

### 🛡️ [Antiphishing](https://github.com/julioliraup/Antiphishing)

**Open-source phishing intelligence and Suricata detection ruleset.**

Antiphishing transforms public phishing intelligence into network detections for Suricata IDS/IPS.

The project includes detection through:

- HTTP
- TLS/SNI
- DNS
- IPv4 reputation datasets
- Phishing intelligence feeds
- Newly Registered Domains (NRD)
- Typosquatting and homoglyph analysis

The project is designed around open threat intelligence and automated rule generation.

**Detection Engineering · Threat Intelligence · Suricata · IDS/IPS · Open Source**

## Open Source & Detection Engineering

My security work has also involved creating and maintaining detection signatures and integrating security research into existing security ecosystems.

### Suricata

I develop Suricata-compatible signatures and datasets for phishing detection, with a focus on converting threat intelligence into network-level detections.
